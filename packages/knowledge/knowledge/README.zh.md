# @deepseek-ai/dsh-knowledge

[English](README.md) | 中文

Curupira Memória 的提供方无关知识 seam。它通过 `ctx.knowledge` 负责提取器和存储注册、内容寻址摄取、确定性段落切分、来源信息、检索、文档列表、相关文档查找和删除。

## 配置

- `store` 选择一个已注册存储；未设置时，必须恰好存在一个可用存储。
- `passageChars` 控制目标检索段落大小，默认值为 `1200`。
- `passageOverlapChars` 重复边界上下文，默认值为 `150`。

该 seam 在存储前对原始字节计算哈希，因此再次摄取相同内容会报告 `alreadyPresent`，而不会产生重复数据。

## 模型体验

### 知识服务

#### 模型所见

模型不会直接看到任何内容。`@deepseek-ai/dsh-knowledge-tools` 等消费方决定检索段落、来源信息和工具 schema 何时进入模型请求。

#### Token 影响

该服务本身不增加 token。插入搜索结果的消费方需要为选中的段落文本和来源信息支付 token 成本。

#### KV Cache 影响

没有直接影响。消费方插入的段落会从插入位置起改变请求，并可能阻止该位置之后的缓存复用。

## 已知限制与后续工作

- 该包本身不提供提取器或持久存储。
- 当可用存储为零个或多个且未配置 `store` 时，存储选择会明确失败。
- 段落切分基于字符；格式特定结构仅来自提取器区域。
