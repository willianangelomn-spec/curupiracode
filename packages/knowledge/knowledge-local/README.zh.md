# @deepseek-ai/dsh-knowledge-local

[English](README.md) | 中文

本地优先的 Curupira Memória 存储。它在版本化知识库中保存内容寻址的原始文件和段落，使用 SQLite FTS5 索引词法搜索，并可通过本地缓存的 Hugging Face 模型增加多语言神经检索。

## 配置

- `root` 选择知识库目录，默认位于 Curupira 主目录下。
- `semantic` 启用本地神经检索，默认值为 `true`。
- `model` 选择缓存在知识库下的 Hugging Face 嵌入模型。

当语义模型无法加载时，存储只报告一次问题，然后继续使用词法搜索。

## 模型体验

### 本地检索

#### 模型所见

模型不会直接看到任何内容。搜索消费方可以公开本地存储返回的排序 `KnowledgeSearchResult` 段落和来源信息；原始文件和嵌入对模型不可见。

#### Token 影响

嵌入和检索在本地执行，不消耗 LLM token。只有插入后续模型请求的段落会贡献 token。

#### KV Cache 影响

该存储不会直接影响提供方缓存。不同搜索结果可能改变消费方插入的上下文，并使插入点之后的复用失效。

## 已知限制与后续工作

- 第一次使用语义功能时可能下载已配置模型，因此需要网络访问。
- 语义功能失败时会降级为词法检索，而不会阻塞知识库。
- 索引仅属于一个知识库根目录，不包含跨计算机同步。
